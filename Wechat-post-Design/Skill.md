# 🚀 微信公众号个性化排版指南（Code with SOLO 模式）

## 🎯 核心痛点与解决方案

**痛点：**
市面上现有的微信公众号推文排版工具（如 135、秀米等）虽然方便，但模板同质化严重、美观度受限，缺乏独特的品牌辨识度。

**解决方案：**
使用 **Code with SOLO** 模式，通过编写 **HTML + CSS** 的方式，从零定制一套专属的微信公众号排版模板。
这种方式不仅能打破排版的千篇一律，还能将品牌色、独特几何图形和排版节奏融入代码，形成强烈的 IP 属性。

---

## 🎨 模板设计核心思想

1. **内联样式（Inline CSS）优先**
   - 微信公众号底层的图文编辑器不支持外部 CSS 文件，且会过滤掉许多高级属性（如 `::before`、`::after` 等伪元素）。
   - **核心规则：** 必须将所有的 CSS 样式直接写在 HTML 标签的 `style="..."` 属性中，并使用真实的 DOM 标签（如 `section`, `span`）来构建模块。
2. **确立主视觉体系**
   - 在开始编码前，必须确立一套品牌主色调。
   - 本次设计确立的【淡绿色与明黄色】主题参数：
     - **深绿色（主文字/边框色）**：`#2D6A4F`
     - **淡绿色（背景/辅助色）**：`#D8F3DC`
     - **明黄色（强调/点缀色）**：`#FFD166`
3. **参数微调提升阅读体验**
   - 不使用纯黑（`#000`），改用柔和的深灰（如 `#3f3f3f`）。
   - 经典的沉浸式段落参数：字号 `15px`，行高 `1.8`，字间距 `1px`，配合 `text-align: justify`（两端对齐）。

## 🧩 核心组件模块清单

为了保证模板的复用性和完整度，我们将整套排版拆分为以下 10 个独立且高度定制化的模块，并分别为其编写了 HTML 代码：

### 1. 顶部关注引导
- **极简下划线引导**：用明黄色下划线替代微信默认的蓝色。
- **胶囊按钮引导**：淡绿色背景、深绿色边框的点击胶囊。
- **虚线边框卡片引导**：支持放置品牌 Slogan 和模拟的关注按钮。

### 2. 头图 / Banner
- **悬浮胶带固定风**：CSS 模拟半透明黄色胶带，适合日常生活/文艺配图。
- **经典错位阴影相框**：硬朗的新粗野主义风格，淡绿色底层阴影块 + 深绿色粗边框。

### 3. 导语 / 开场白
- **经典引言框**：巨大双引号背景装饰，适合文艺开场。
- **便签纸折角风**：右上角 CSS 模拟纸张折角，适合知识干货总结。

### 4. 标题体系
- **一级/主标题**：强视觉冲击力（如错位立体字效、双色渐变横幅）。
- **二/三级小标题**：轻量级层次划分（如极简黄点指引、胶囊序号标签）。

### 5. 分割线
- 替代微信单调横线。如经典三点居中、黄绿拼接彩带、文字断点线。

### 6. 正文标准段落
- **经典沉浸式排版**（主流黄金比例）。
- **首行缩进排版**（适合严肃长文）。
- **大字号适老排版**（17px 字号，适合特定受众）。

### 7. 多图 / 网格排版
*突破微信默认单图排列的限制，使用 Flex 布局结合 `object-fit: cover` 实现：*
- **等宽双图并排**（对比照）。
- **主次三图拼贴**（左大图+右两小图）。
- **九宫格并排**。

### 8. 视 / 音频外框
*专门为微信自带的视频/音频组件设计的装饰框：*
- **经典电视机外框**（适合视频）。
- **唱片机复古外框**（适合音频）。

### 9. 互动与底部模块
- **Q&A 对话框**：模拟微信聊天气泡。
- **时间轴/步骤条**：CSS 左边框构建的垂直历程线。
- **作者名片**：包含头像、简介和二维码的高级卡片。
- **引导三连**：CSS 绘制的“分享、点赞、在看”按钮。
- **延伸阅读**：往期文章推荐列表。

## 🛠️ 交付物与使用指南

我们最终将上述所有模块整合到了一个**可翻页的 Web 图册（HTML 文件）**中。

### 📌 如何在微信公众号中使用？

1. **打开图册**
   - 在浏览器中双击打开生成的图册 HTML 文件。左侧为导航菜单，右侧为手机壳预览区。
2. **框选复制**
   - 在右侧的手机屏幕预览区，**用鼠标直接框选**你喜欢的模块（从外边框一直框选到底部）。
   - 按下 `Ctrl+C`（Mac: `Cmd+C`）进行复制。
3. **粘贴到后台**
   - 打开微信公众号的图文素材编辑器，在空白处按下 `Ctrl+V`（Mac: `Cmd+V`）粘贴。
   - **注意**：粘贴后，所有的 CSS 样式会被完美保留！
4. **修改内容**
   - **文字**：直接在微信编辑器里点击文字进行修改。
   - **图片**：点击模块里的占位图片，选择微信编辑器的“替换”功能上传本地图片，图片会自动适应代码写好的外框和比例。
   - **视/音频**：对于特殊外框，先在微信后台插入真实的视/音频组件，然后用鼠标将其**拖拽**进外框的灰色占位区域中。

### 💡 进阶建议
建议在微信公众号后台建立一个名为“草稿素材库”的文章，将你最常用的 HTML 模块全部粘贴进去保存。每次写新文章时，直接从这个草稿里复制模块即可，彻底摆脱第三方排版工具！
