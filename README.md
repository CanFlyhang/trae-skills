# TRAE Skills 分享仓库

## 仓库介绍

这是字节跳动TRAE校园合作伙伴 **CanFlyhang** 在开发实践中积累的 skills 分享仓库。我们希望通过这个仓库，为大家提供一些开发实践中的启发和便利，同时也欢迎所有开发者上传自己的 skills，让这个仓库变得更加丰富和有价值。

## 什么是 TRAE Skills？

TRAE Skills 是一种可复用的能力模块，用于扩展 TRAE IDE 的功能。通过 skills，你可以：

- 封装特定领域的专业知识和工作流程
- 标准化开发过程中的重复任务
- 分享自己的开发经验和最佳实践
- 快速应用他人的解决方案到自己的项目中

## 如何使用本仓库

1. **浏览现有 skills**：查看仓库中的技能目录，了解不同技能的功能和使用方法
2. **下载技能**：将感兴趣的技能目录复制到你的 TRAE 工作区的 `.trae/skills/` 目录下
3. **使用技能**：在 TRAE IDE 中，技能会自动被识别并可在相关场景中使用

## 如何贡献技能

我们非常欢迎你贡献自己的技能到这个仓库！贡献步骤如下：

1. **Fork 本仓库**：在 GitHub 上 fork 这个仓库到你的个人账号
2. **创建技能**：
   - 在本地创建技能目录，目录名建议使用小写字母和连字符
   - 在目录中创建 `SKILL.md` 文件，按照 TRAE skills 的格式编写技能定义
3. **提交更改**：
   - 将你的技能目录添加到仓库中
   - 提交 commit，并添加清晰的 commit 信息
4. **创建 Pull Request**：向本仓库提交 Pull Request，我们会审核并合并你的贡献

## 技能编写指南

- **技能名称**：使用清晰、描述性的名称，反映技能的核心功能
- **技能描述**：简要说明技能的功能和适用场景
- **技能内容**：详细描述技能的执行步骤、输出格式和约束规则
- **格式规范**：遵循 TRAE skills 的 Markdown 格式规范
